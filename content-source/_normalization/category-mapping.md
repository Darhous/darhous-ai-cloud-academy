# Category Mapping

This document maps the `portal_id` to a stable, reusable Arabic `category` for normalization, as required by the strict normalization rules.

| `portal_id` | `category` (Arabic) |
|-------------|----------------------|
| `ai-academy` | الذكاء الاصطناعي |
| `automation` | الأتمتة |
| `career` | المسار المهني |
| `digital-exams` | الاختبارات الرقمية |
| `iot-lab` | إنترنت الأشياء |
| `language` | تعلم اللغات |
| `nano-banana` | نانو بانانا |
| `tools-hub` | منصة الأدوات |

> [!NOTE]
> These categories are used when the original file lacks a `category` field. This ensures a deterministic, predictable category structure instead of generating random ones.
