# Arduino أم ESP32 أم Raspberry Pi؟

الاختيار يبدأ بالمشروع، لا باسم اللوحة. المتحكم الدقيق مناسب للتحكم المباشر، بينما Raspberry Pi حاسوب صغير يشغل نظام تشغيل.

## مقارنة عملية

- **Arduino:** بداية واضحة للتحكم في LED ومحركات وحساسات بسيطة.
- **ESP32:** متحكم مع Wi-Fi وBluetooth، مناسب لمشاريع IoT منخفضة التكلفة.
- **Raspberry Pi:** مناسب للواجهات والكاميرات والخدمات التي تحتاج Linux وقدرة معالجة أعلى.

## قالب الاختيار

```text
هل أحتاج نظام تشغيل؟ نعم → Raspberry Pi
هل أحتاج Wi-Fi مع تحكم مباشر؟ نعم → ESP32
هل أتعلم الأساسيات أو أحتاج دائرة بسيطة؟ → Arduino
```

## أخطاء شائعة

استخدام Pi لمهمة LED بسيطة، أو تجاهل اختلاف 3.3V و5V، أو شراء لوحة قبل حصر المداخل والمخارج.

## تمرين

اكتب متطلبات مشروعك في خمسة أسطر: الحساسات، الاتصال، الطاقة، الاستجابة، والميزانية. اختر لوحة واذكر سببين قابلين للقياس.

## القرار يبدأ من طبيعة المهمة

Arduino وESP32 متحكمان دقيقان: يشغّلان برنامجًا مخصصًا ويستجيبان للأطراف بسرعة وتوقع أعلى من حاسوب يشغل نظام تشغيل. Raspberry Pi حاسوب Linux صغير؛ يناسب الكاميرا، قواعد البيانات المحلية، الواجهات، وتشغيل عدة خدمات. هذا الاختلاف أهم من مقارنة سرعة المعالج وحدها.

لإشارة باب أو حساس حرارة يعمل بالبطارية ويرسل رسالة صغيرة، يكون ESP32 غالبًا مرشحًا جيدًا لأنه يجمع الأطراف والاتصال. لتعلّم LED والزر والحساسات دون حاجة للشبكة، تبسط لوحة Arduino التجربة. أما تحليل صور كاميرا وعرض واجهة محلية وتخزين ملفات، فـ Raspberry Pi أقرب للمطلوب، مع بقاء احتمال استخدام متحكم منفصل للقراءات الحساسة زمنيًا.

## مصفوفة اختيار قابلة للقياس

قيّم كل خيار من 1 إلى 5 في: عدد الأطراف، الجهد، Wi-Fi، استهلاك الطاقة، زمن الإقلاع، المكتبات، نظام التشغيل، والسعر الكلي مع الملحقات. لا تعط كل معيار الوزن نفسه. جهاز يعمل بالبطارية يعطي الطاقة وزنًا أكبر، ومحطة كاميرا تعطي الذاكرة ونظام التشغيل وزنًا أكبر.

مثال: مراقب حرارة يرسل كل خمس دقائق لا يحتاج شاشة HDMI أو نظام ملفات كاملًا. اختيار Pi هنا يزيد الطاقة والتعقيد بلا قيمة واضحة. وفي المقابل، محاولة تشغيل نموذج رؤية حاسوبية على Arduino غير واقعية.

## حدود يجب فحصها

راجع Datasheet للجهد والتيار، فبعض أطراف ESP32 تعمل بمنطق 3.3V ولا تتحمل 5V. احسب أيضًا عدد ADC وPWM وواجهات I2C أو SPI المطلوبة، ولا تعتمد على العدد المكتوب على اللوحة دون معرفة الأطراف المحجوزة.

## خطوة اليوم

أنشئ جدولًا لثلاث لوحات أمام مشروع واحد، وحدد ثلاثة معايير حاسمة وأوزانها. اختر الفائز بالحساب، ثم اكتب سببًا قد يجعلك تغيّر القرار.
