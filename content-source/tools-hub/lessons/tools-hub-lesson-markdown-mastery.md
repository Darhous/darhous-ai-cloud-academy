# إتقان الماركداون لكتابة أسرع

الـ Markdown هو طريقك للكتابة بدون رفع يدك عن لوحة المفاتيح لاستخدام الفأرة. تعلم الأساسيات: نجمة واحدة للمائل، نجمتين للعريض، وعلامة المربع للعناوين. هذه المهارة ستجعلك أسرع في استخدام أدوات مثل Obsidian و Notion.
