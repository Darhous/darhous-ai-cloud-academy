# توثيق أدواتك وعملياتك (SOPs)

اكتب دليلاً صغيراً يوضح كيف تستخدم أدواتك. هذا سيفيدك إذا قررت تفويض المهام لشخص آخر، أو حتى كنقطة مرجعية لنفسك لضمان عدم تشتت استخدامك. حدد بوضوح أين تُحفظ الملفات وكيف تُسمى لضمان النظام.
