# تعلم الأتمتة باستخدام n8n

n8n يساعدك على رؤية البيانات وهي تنتقل بين Nodes. استخدمه أولًا كمعمل تجريبي، لا كنظام إنتاج.

## أول تجربة

1. أنشئ Trigger يدويًا.
2. أضف بيانات تجريبية مثل الاسم والبريد.
3. أضف خطوة تحول الاسم إلى صيغة موحدة.
4. أضف شرطًا يتحقق من وجود البريد.
5. شغّل كل خطوة وافحص Input وOutput.

## مخطط مصغر

```text
Manual Trigger
→ Sample Data
→ Normalize Fields
→ If Email Exists
→ Success / Review
```

## ما الذي تتعلمه؟

ستفهم بنية JSON، وربط الحقول، والفروع، وسبب فشل خطوة عندما لا تجد القيمة المتوقعة.

## أخطاء شائعة

- نسخ Workflow جاهز دون فهم البيانات.
- ربط حسابات حقيقية مبكرًا.
- عدم تثبيت أسماء الحقول.
- تشغيل حلقات أو جداول كبيرة أثناء التعلم.

## افهم البيانات قبل زيادة عدد Nodes

افتح نتيجة كل Node ولاحظ أن n8n يمرر Items غالبًا في صورة JSON. دوّن مسار الحقول التي تستخدمها، مثل email أو request.id، ولا تعتمد على السحب البصري دون فهم الاسم الفعلي. غيّر سجلًا واحدًا عمدًا لترى ماذا يحدث عندما يكون الحقل غير موجود أو من نوع مختلف.

في خطوة التوحيد، لا تكتف بتحويل الاسم. أنشئ حقولًا واضحة مثل normalized_email وvalidation_status وvalidation_reason. هذا يجعل الفروع التالية مقروءة ويمنع تكرار نفس المنطق. في If Node، وجه السليم لمسار نجاح والناقص لمسار مراجعة يحفظ السبب؛ لا تترك الفرع غير المستخدم بلا نتيجة.

## مختبر من ثلاث جولات

الجولة الأولى تشغيل يدوي بلا تكاملات. الجولة الثانية إضافة جدول تجريبي مع صلاحية محدودة. الجولة الثالثة محاكاة خطأ بإزالة حقل أو استخدام اسم جدول غير صحيح. في كل جولة سجل execution id، والمدخل، وآخر Node نجحت، والنتيجة. الهدف تعلم التشخيص، لا مجرد مشاهدة المسار الأخضر.

عند إضافة خدمة خارجية، اختبر سجلًا واحدًا وحدد ما إذا كانت Node تنشئ أثرًا يمكن تكراره. إذا أنشأت صفًا أو رسالة، احفظ المعرف الناتج وابحث عنه قبل إعادة المحاولة. استخدم أسماء مثل `Validate Required Fields` و`Route Missing Data` بدل `Set1` و`If2`.

## شروط الانتقال لمشروع حقيقي

يجب أن تستطيع شرح كل تعبير، وتمييز بيانات الاعتماد عن بيانات Workflow، ومعالجة سجل ناقص دون توقف الكل، وتحديد ما يحدث عند إعادة التنفيذ. صدّر توثيقًا أو ارسم المسار، واكتب قائمة بالحقول والصلاحيات والتنبيهات. لا تربط حسابًا حقيقيًا قبل مراجعة هذه القائمة مع مالك العملية.

## تمرين

ابنِ المسار السابق بثلاثة سجلات: صحيح، بريد ناقص، واسم فارغ. سجل مسار كل سجل والنتيجة التي وصل إليها.
