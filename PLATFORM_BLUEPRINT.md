# 🏛️ Platform Blueprint — Darhous AI Cloud Academy

## Product Vision

**Darhous AI Cloud Academy** is the **premier Arabic-language AI and Cloud learning platform** — a premium, practical, community-driven education hub that takes Arab learners from zero to building real-world AI projects.

We are NOT just a course platform. We are an **AI learning operating system** that combines:
- Structured courses and learning paths
- An AI tools command center
- A Claude mastery hub
- Cloud infrastructure training
- A real-world project library
- A professional prompt library
- A vibrant Arabic AI community

## Learning Strategy

### Principle 1: Learn by Building
Every course ends with a real project. Theory is minimized. Hands-on practice is maximized.

### Principle 2: Stack-Based Learning
We teach tools in context of each other. Not "here's a tool," but "here's a stack that solves this problem."

### Principle 3: Arabic First
All core content is available in Arabic. English is provided for technical terms and for international accessibility.

### Principle 4: Free Floor, Premium Ceiling
Core content is always free. Premium features (certificates, AI assistant, cloud labs) are paid.
