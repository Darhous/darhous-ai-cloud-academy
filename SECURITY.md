# Security Policy

## Supported Project Status

Security reports are accepted for the current production platform and the latest code on the `main` branch. Older deployments, forks, and unofficial copies are not supported.

## Reporting a Vulnerability

Report suspected vulnerabilities privately by emailing [ahmeddarhous@gmail.com](mailto:ahmeddarhous@gmail.com).

Do not open a public issue or discussion for a security vulnerability. Do not include credentials, personal data, exploit details, or other sensitive incident information in public channels.

Please report issues involving:

- Exposed credentials or sensitive configuration
- Authentication or authorization bypasses
- Abuse of AI endpoints or resource controls
- Certificate issuing or verification abuse
- Data privacy, disclosure, or integrity risks

Include a concise description, affected area, reproduction steps, and potential impact where safe to do so. Reports will be reviewed under responsible disclosure principles. Please allow reasonable time for investigation and remediation before publishing any details.
