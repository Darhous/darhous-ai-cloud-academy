## Manual Owner Actions

### Social Preview

In GitHub, open **Settings → Social preview** and upload a polished 1200×630 or 1280×640 image. The existing `public/og-image.svg` is a suitable visual reference, but a PNG export is preferred for the repository preview.

### Branch Protection

In GitHub, open **Settings → Branches → Add rule** for `main`, then consider:

- Require a pull request before merging
- Require status checks to pass
- Require conversation resolution, if desired

Do not enable overly strict rules until the owner confirms the intended contribution and release workflow.
