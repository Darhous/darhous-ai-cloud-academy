## ⚙️ القواعد التشغيلية الدائمة (إلزامية لكل Phase تنفيذية)

1. **العمل على `main` فقط** بعد Phase 0.
2. **دورة العمل لكل phase:**
   `typecheck → lint → build (exit 0) → commit → safety+phase tag → push to main → Vercel live check → release decision`
3. **Safety tag** (`checkpoint/pre-<phase>`) قبل أي تعديل.
4. المستخدم **يراقب اللايف على Vercel** — كل تعديل يجب أن يصبح **live على GitHub `main`**.
5. ⚠️ **Next.js غير قياسي** — اقرأ `node_modules/next/dist/docs/` ذات الصلة قبل أي كود (AGENTS.md).
6. **مرحلة واحدة في كل مرة** — لا تبدأ التالية إلا بعد تأكيد المستخدم.
7. **إضافة فقط** — لا تكسر محتوى/وظيفة قائمة.
8. تحديث `CLAUDE_CONTINUATION_CONTEXT.md` بعد كل phase.
9. **GitHub Release رسمي** عند المعالم الكبرى فقط (مش كل tag).
