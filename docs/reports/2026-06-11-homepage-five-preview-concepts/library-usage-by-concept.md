# Library Usage By Concept

**Date:** 2026-06-11

## Concept 1: AI Command Center
- **shadcn/ui**: Used for standard cards, badges, and layout primitives.
- **HeroUI**: Action controls, buttons, and inputs.
- **Magic UI**: Shimmer buttons for CTA emphasis.
- **Aceternity**: Bento grid layout and subtle background beams.
- **UI/UX Pro Max**: Hierarchy enforced (dark theme, distinct portal colors).

## Concept 2: The Learning Journey
- **shadcn/ui**: Milestone cards and timeline points.
- **Magic UI**: Gentle rotation and typography emphasis.
- **Aceternity**: Story bento for the 3-step timeline.
- **HeroUI**: Interactive CTA buttons.
- **UI/UX Pro Max**: Focus on clarity and accessible contrast ratios.

## Concept 3: Silent Authority
- **shadcn/ui**: Refined border-cards, trust badges, minimal grid.
- **HeroUI**: Clean controls, form elements.
- **Magic UI**: Intentionally avoided to keep it minimal.
- **Aceternity**: Intentionally avoided to keep it minimal.
- **UI/UX Pro Max**: Editorial layout, strong typography constraints.

## Concept 4: Portal Constellation
- **Aceternity**: Heavily used for the glowing orbs, space background, and 3D floating panels.
- **Magic UI**: Animated background depth and grid lines.
- **shadcn/ui**: Used as a fallback for standard text cards within the portal detail view.
- **HeroUI**: Intentionally avoided (too standard for a 3D interface).
- **UI/UX Pro Max**: Prevented visual chaos by constraining orb colors to the brand palette.

## Concept 5: Goal Gateway
- **HeroUI**: Large selection tabs, buttons, interactive choice cards.
- **shadcn/ui**: Goal result cards, clean structured layout.
- **Magic UI**: CTA glow and emphasis.
- **Aceternity**: Recommendation bento hover effects.
- **UI/UX Pro Max**: Conversion clarity, strict touch-target sizing (min 48px).
