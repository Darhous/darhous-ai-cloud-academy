## مقدمة

**Prompt Engineering** هو فن وعلم كتابة التعليمات للنماذج اللغوية الكبيرة (LLMs) للحصول على النتائج المطلوبة بدقة وكفاءة. مع انتشار نماذج مثل Claude وGPT-4 وGemini، أصبح هذا المجال من أهم المهارات في عصر AI.

## لماذا يهمّ Prompt Engineering؟

النموذج اللغوي ليس آلة بحث — إنه نظام توليد نص يعتمد على السياق. الفرق بين برومبت جيد وسيء قد يكون الفرق بين:
- إجابة مفيدة مفصّلة ← نتيجة ممتازة
- إجابة عامة غير دقيقة ← نتيجة مخيبة

## المبادئ الأساسية الخمسة

### 1. الوضوح والتحديد

كن محدداً في طلبك. بدلاً من "اكتب مقالاً عن AI"، قل "اكتب مقال 500 كلمة موجّه للمبتدئين عن تطبيقات الذكاء الاصطناعي في الطب، بأسلوب بسيط وأمثلة عملية".

```
❌ "اشرح الذكاء الاصطناعي"
✅ "اشرح الذكاء الاصطناعي لطالب ثانوية في 3 نقاط مع مثال يومي لكل نقطة"
```

### 2. تحديد الدور (Role Prompting)

أخبر النموذج من هو في هذه المحادثة:

```
"أنت خبير في أمن المعلومات مع خبرة 15 سنة..."
"تصرّف كمعلم صبور يشرح للأطفال..."
```

### 3. أمثلة (Few-Shot Prompting)

أعطِ النموذج أمثلة على ما تريد:

```
ترجم هذه الجمل للعربية بأسلوب رسمي:
Input: "Good morning" → Output: "صباح الخير"
Input: "Thank you" → Output: "شكراً جزيلاً"
Input: "See you tomorrow" → Output: ?
```

### 4. التفكير التسلسلي (Chain of Thought)

اطلب من النموذج أن يفكر خطوة بخطوة:

```
"قبل أن تجيب، فكّر بصوت عالٍ في الخطوات المطلوبة"
"Let's think step by step"
```

### 5. تحديد الصيغة والطول

```
"أجب في قائمة نقطية من 5 عناصر"
"اكتب بلغة JSON مع الحقول: name, description, example"
"لا تتجاوز 200 كلمة"
```

## تقنيات متقدمة

### Prompt Chaining
قسّم المهمة المعقدة لسلسلة من البرومبتات البسيطة. كل برومبت يستخدم ناتج السابق.

### System Prompts
في Claude وGPT-4 API، يمكنك تعريف شخصية وقواعد ثابتة للمحادثة كلها.

### Temperature Control
- **Temperature 0**: إجابات محددة ومتسقة (أفضل للحقائق والكود)
- **Temperature 1+**: إجابات إبداعية ومتنوعة (أفضل للكتابة الإبداعية)

## أدوات ومصادر

- **Claude.ai** — أفضل نموذج لمتابعة التعليمات المعقدة
- **PromptBase** — مكتبة برومبتات جاهزة
- **Anthropic Docs** — وثائق Claude الرسمية

## خلاصة

Prompt Engineering ليس سحراً — إنه مهارة قابلة للتعلم. ابدأ بالأساسيات، جرّب كثيراً، ولاحظ الفروق. كل نموذج له شخصيته وأفضل طريقة للتواصل معه.

> **نصيحة أخيرة:** احتفظ بمكتبة شخصية لأفضل برومبتاتك. هذا سيوفّر عليك وقتاً كبيراً.
